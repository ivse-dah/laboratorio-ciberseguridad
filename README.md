# Laboratorio de Kali Linux en el Navegador

Entorno oficial de Kali Linux con entorno gráfico XFCE y herramientas de pentesting preinstaladas.

Haz clic en el siguiente botón para iniciar el laboratorio en la nube:

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ivse-dah/laboratorio-ciberseguridad)

---

### Instrucciones de acceso:
1. Al hacer clic en el botón, espera 2 a 3 minutos mientras se levanta el entorno.
2. Ve a la pestaña inferior **Puertos** (Ports).
3. Haz clic en el icono del **globo terráqueo** en el puerto `6080` (o dale a la notificación emergente).
4. En la pestaña de noVNC, haz clic en **Connect** para ver el escritorio de Kali.
